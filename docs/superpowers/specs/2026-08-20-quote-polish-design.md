## ב. הצעת המחיר בדף הסוכן

### מקור אמת יחיד לסכומים

```
orderTotals()            → subtotal / discount / shipping / total   (קיים)
        ↓
quoteTotals(net)         → net / vat / gross / rounded              (חדש)
```

`quoteTotals` הוא הפונקציה היחידה שמחשבת מע״מ ועיגול:

```js
var VAT_RATE = 0.18;
net   = orderTotals().total
vat   = net * VAT_RATE
gross = round ? Math.round(net + vat) : net + vat
vat   = gross - net        // ← נגזר בחזרה, כדי שהשורות תמיד יסתכמו
```

**העיגול מתבצע על הסה״כ ואז המע״מ נגזר ממנו** ולא להפך. אחרת המסמך היה מציג
שלוש שורות שאינן מסתכמות לסכום שכתוב בהן — בדיוק התקלה שתוקנה בסבב 33.

### בלוק סיכום מודפס

`printQuote()` מזריק בין הטבלה לחתימות בלוק `.q-sum` בשלוש שורות: סכום ביניים ·
מע״מ 18% · סה״כ לתשלום (רצועה ירוקה כהה). כשהעיגול פעיל מופיעה ליד הסה״כ
המילה "(מעוגל)". סיכום ה-`modal-footer` **מוסתר בהדפסה** כדי שלא יופיע פעמיים,
וכך הסכום ממילא מודפס לפני החתימות — הליקוי מס' 3 נסגר מבנית ולא בתיקון CSS.

### שאר התיקונים

* **תאריך:** בהדפסה מוסתר `#order-date-field` ומוצג `#order-date-display`
  (האלמנט כבר קיים ומתוחזק ב-`setupDate`, רק היה `display:none`).
* **מספר הצעה:** `Q-YYYYMMDD-NNNN` — אותה תבנית כמו מספר ההזמנה (`AR-…`).
  ה-4 ספרות נגזרות מה-timestamp, כך שאין התנגשות בין שתי הצעות באותו יום.
* **לוגו:** 46px → 60px בכותרת ההדפסה.

### תיחום

כל כללי ההדפסה החדשים מגודרים תחת `body.quote-print` — class שנוסף בתחילת
`printQuote` ומוסר בסופה. כך `@media print` הקיים של שאר הקטלוגים לא משתנה.
תיבת הסימון ובלוק המע״מ מותנים ב-`CONFIG.quoteVat` (ברירת מחדל `false`,
מופעל רק ב-`agent/index.html`), ולכן `/catalog/`, `/care/` ו-`/emp-8c3f5a/`
אינם מושפעים.
