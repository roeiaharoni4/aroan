# מחירון נסתר + מערכת עריכה — מסמך עיצוב (16.7.26)

## מטרה
עמוד קטלוג נסתר (נגיש רק בקישור ישיר) עם מוצרים שונים מהקטלוג הראשי ועם מחירי מכירה מוצגים,
ומערכת עריכה מקומית נפרדת עם עלות/מכירה/אחוז רווח והעלאת CSV.

## החלטות שאושרו ע"י רועי
- מחיר עלות נשאר **מקומי בלבד** — לא נדחף ל-git ולא עולה לאתר.
- הגנה: **קישור חשאי בלבד** (בלי קוד כניסה).
- העלאת CSV: **מיזוג לפי מזהה/שם** (לא החלפה מלאה).
- מהעמוד אפשר **להזמין** (עגלה + וואטסאפ/מייל) כמו בקטלוג הרגיל.
- אחוז רווח = **רווח מהעלות**: `רווח% = (מכירה − עלות) / עלות × 100`.

## רכיבים

### 1. עמוד נסתר — `/p-3167edfa/index.html`
- מבוסס על `catalog/index.html` (חוויית לקוח מלאה: סרגל צד, עגלה, פרטי לקוח, אישור הזמנה).
- `CATALOG_CONFIG`: `showPrices: true`, `allowPdf: false`, `allowShare: false`,
  `dataSource: '/data/pricelist.csv?v=1'` (חדש — ראה שינוי app.js).
- `<meta name="robots" content="noindex, nofollow">`, בלי canonical/OG/סכמה.
- **לא** נוסף ל-sitemap, ל-llms.txt או ל-robots.txt — הוספה ל-robots.txt הייתה חושפת את הכתובת.
- לא מקושר משום עמוד באתר.

### 2. נתונים — שני קבצים ב-`data/`
- `pricelist-master.csv` — **מקומי בלבד, ב-.gitignore**. עמודות:
  `id,name,category,unit,image,cost,price,description`.
- `pricelist.csv` — הקובץ שנדחף לאתר. עמודות זהות ל-products.csv:
  `id,name,category,unit,image,price,description` (מחיר מכירה בלבד, בלי עלות).
- הקובץ הציבורי נוצר אוטומטית מהמקומי בכל שמירה בעורך.

### 3. מערכת עריכה — `/admin/pricelist.html` + `pricelist.js`
- עובדת רק מקומית דרך `start_catalog.command` (אותה חסימת hostname כמו admin הקיים), משתמשת ב-`admin.css`.
- טבלה: תמונה, מק"ט, שם, קטגוריה, עלות, מכירה, רווח %, פעולות.
- מודאל עריכה עם שלושת שדות המחיר — הזנת כל שניים מחשבת את השלישי:
  - עריכת עלות: אם יש מכירה → מעדכן רווח; אחרת אם יש רווח → מעדכן מכירה.
  - עריכת מכירה: אם יש עלות → מעדכן רווח; אחרת אם יש רווח → מעדכן עלות.
  - עריכת רווח: אם יש עלות → מעדכן מכירה; אחרת אם יש מכירה → מעדכן עלות.
- העלאת תמונות דרך `/api/upload` הקיים.
- **העלאת CSV**: PapaParse (העותק המקומי `/js/lib/papaparse.min.js`), זיהוי כותרות גמיש
  בעברית/אנגלית (מזהה/מק"ט/id, שם/name, עלות/cost, מכירה/מחיר/price, רווח/margin, ...),
  השלמת שדה מחיר חסר משני האחרים, מיזוג לפי id (ואם אין — לפי שם מדויק),
  תצוגה מקדימה ("X עודכנו, Y חדשים") לפני החלה. שורות חדשות בלי מזהה מקבלות מזהה אוטומטי PLxxx.
- טעינה: `pricelist-master.csv`; אם חסר (מחשב חדש) — נופל ל-`pricelist.csv` בלי עלויות.
- שמירה: `POST /api/pricelist`.

### 4. server.py
- endpoint חדש `/api/pricelist`: מקבל JSON, כותב את הקובץ המקומי (עם cost)
  ואת הקובץ הציבורי (בלי cost) בסדר עמודות קבוע.

### 5. שינוי יחיד ב-app.js
- שורה 2: `DATA_SOURCE_URL` מקבל override מ-`window.CATALOG_CONFIG.dataSource` אם הוגדר.
  כל הדפים הקיימים ממשיכים כרגיל. גרסה: `app.js?v=20` (13 דפים), `sw.js` → cache-v7.

### 6. שונות
- `.gitignore` חדש עם `data/pricelist-master.csv`.
- קישור לעורך המחירון מתפריט הצד של admin הקיים (ולהפך) — נגיש רק מקומית ממילא.
- `הזמנות אחרונות` כבר מופרדות לפי נתיב (RECENT_KEY) — אין דליפה בין הקטלוגים.

## בדיקות
בדפדפן מול server.py: העמוד הנסתר טוען את pricelist.csv עם מחירים; עגלה + מודאל הזמנה;
העורך — חישוב תלת-כיווני, העלאת CSV עם מיזוג, שמירה שכותבת את שני הקבצים; ודיפוי שהקטלוג הרגיל לא נפגע.
